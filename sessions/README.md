# Sessions

One file per day: `YYYY-MM-DD.md`. Append at the end of each work block and before a handover, because the conversation is compacted and files are not.

```
## <block title>
- Ran / read: <commands, files, URLs>
- Guess → result: <what you expected, what happened, with numbers>
- Sources: <which part came from which source, when there are several>
- Cost: <tokens or money, if any>
- Open: <doubts, decisions waiting for the user>
- Next: <one step>
```
